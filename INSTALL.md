# Installing

## From GitHub (recommended)

In any Claude Code session, terminal or the desktop app's Code tab:

```
/plugin install model-router --marketplace laythwhite/model-router
```

Answer `y` to add the marketplace, then press Enter to install. Start a new session and run `/route` to confirm.

From a terminal, the same thing is:

```
claude plugin marketplace add laythwhite/model-router
claude plugin install model-router@model-router
```

**Updates:** bump `version` in `.claude-plugin/plugin.json`, push, then run `/plugin marketplace update model-router` and `/reload-plugins`.

## From a local folder

Clone or unzip the repo somewhere permanent, e.g. `~/claude-mods/model-router/`, then either:

- **Desktop app:** add this to `~/.claude/settings.json`, merging it with what's already there, then quit and reopen the app:

  ```json
  {
    "env": {
      "CLAUDE_CODE_PLUGIN_DIRS": "/Users/<you>/claude-mods/model-router"
    }
  }
  ```

- **Terminal:** `claude --plugin-dir ~/claude-mods/model-router`

## Check it's working

- Type `/route`. You should see `Mode: auto`.
- Send something like "fix the typo in the hero headline". The status line should read `⇢ Haiku · low · Quick`.

`.claude-plugin/types/` is generated by the engine when the mod loads. It's gitignored, so don't commit it.
